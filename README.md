# CBOPKA_PK3
Сборка для РК3 (Fabric 1.21.1)

Начало:
Папку "Сборку" вы открываете и всё что там внутри, кидаете в папку ".minecraft"


Для TLauncher (И ему подобных):
".minecraft" является корневой папкой Майнкрафта, и чтобы её открыть нужно нажать сочетание клавиш Win+R и написать %appdata%, после найдите папку "Roaming" и там будет папка ".minecraft" (УБЕДИТЕСЬ, что ваша версия игры FABRIC 1.21.1)


Для PrismLauncher (И ему подобных):
Содержимое папки "Сборка" перекидываете в содержимое вашей сборки в PrismLauncher.
Ваша сборка игры должна быть примерно по такому пути "C:/PrismLauncher/instances/1.21.1/minecraft" и в папку "minecraft" кидаете содержимое папки "Сборка" (УБЕДИТЕСЬ, что ваша версия игры FABRIC 1.21.1)
